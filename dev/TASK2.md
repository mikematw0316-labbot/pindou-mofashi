- 地圖、教學卡、結算、小店、對照表全部重排成手機直式好讀好點的版面（單欄、卡片、底部主要按鈕在拇指區）。

## 4. 鍵盤：按下按鈕 → 系統鍵盤出現 → 遊戲才開始（使用者 11/16 指定）
手機上預設使用**手機系統鍵盤**（使用者自己的拼音輸入法），這樣練到的才是真的拼音輸入。

### 開始流程
- 每關（引導練習與戰鬥）都有明確的「開始」按鈕。在該按鈕的同一個使用者手勢（pointerup／click 處理函式內同步）對一個常駐輸入框呼叫 focus()，讓系統鍵盤彈出（iOS 必須在手勢內 focus）。
- 用 `visualViewport` 的 resize／scroll 事件判斷鍵盤是否已出現（可視高度明顯小於 layout 高度）。確認出現後顯示倒數 3、2、1 才開始出怪／計時。1.5 秒內沒偵測到鍵盤（例如桌機、外接鍵盤、不支援 visualViewport）就視為「有實體鍵盤」，直接倒數開始。
- 鍵盤被收起或輸入框失焦：立即暫停，畫面中央顯示大按鈕「點我繼續」，點擊（手勢內重新 focus）後倒數再繼續。暫停期間怪物與王的蓄力都凍結。
- 戰場與題目只排在 `visualViewport` 的可視範圍內（鍵盤上方）；鍵盤高度改變時重新排版。怪物、題卡、HUD 不可被鍵盤或瀏海遮住。整頁不可因為 focus 而被瀏覽器捲走（固定版面，必要時在 visualViewport scroll 時校正）。
- 輸入框：視覺上是戰場底部一條精簡的「施法列」（顯示目前打的內容），不是隱形的；設 `autocapitalize="off" autocorrect="off" autocomplete="off" spellcheck="false" enterkeyhint="done"`，字級 ≥16px（避免 iOS 自動放大）。

### 判定：同時接受「拼音字母」與「選字送出的國字」
用同一個輸入框，監聽 beforeinput／input／compositionstart／compositionupdate／compositionend：
- **字母路徑**：取輸入框目前內容（含組字中的文字與 compositionupdate 的 data），正規化（轉小寫、去掉空白與撇號 ' 、把 ü 視為 v），得到 raw。用「已消耗前綴」的方式比對：維護 consumed 長度，待比對字串 = raw 從 consumed 之後的部分；它是目標拼音的前綴就逐字母亮起，等於目標拼音就擊倒並把 consumed 推進（不要依賴在組字期間清空輸入框，許多手機輸入法清不掉）。出現不符合任何在場怪物拼音前綴的字母才算打錯。使用者按刪除鍵讓 raw 變短時 consumed 與進度要跟著回退，不算錯。
- **國字路徑**：組字結束（compositionend）或非組字 input 之後，若新送出的文字包含某隻在場怪物的國字／詞（詞要完整相符），就擊倒牠（優先已鎖定的、其次最靠近城門的）。送出的國字不是任何在場怪物的字：算一次打錯（選錯字）。
- 每次擊倒後，在不處於組字狀態時清空輸入框並重設 consumed。
- 組字期間（isComposing）不可把中間狀態判為錯誤，除非字母路徑已確定不符合任何怪物。
- 偵測到輸入內容含注音符號（ㄅ–ㄩ、ˊˇˋ˙）：暫停並顯示「目前是注音鍵盤，請切換到拼音或英文鍵盤」，附 iOS／Android 新增與切換拼音鍵盤（繁體輸出）的步驟，按「我切好了」繼續。
- 第 1 區（聲母韻母片段）只走字母路徑。第 5 區（整句）沿用第一版的整句比對，用同一套開始流程與鍵盤偵測。
- 手機上也可直接點怪來鎖定（點擊後要保持輸入框聚焦，不可讓鍵盤收起：在怪物上用 pointerdown preventDefault 處理）。
- 桌機：實體鍵盤照常；不需要點輸入框也能打（全域鍵盤事件仍有效），但按「開始」同樣會聚焦施法列，行為一致。

### 備用：遊戲內建鍵盤（設定可切換，預設關）
設定中提供「使用遊戲內建鍵盤」。開啟後第 1～4 區不聚焦任何輸入框，改用畫面底部的 QWERTY 三排內建鍵盤（pointerdown 立即觸發、多指連點不漏鍵、按下有回饋、鍵縫判給最近的鍵、另有「偷看」「解除鎖定」鍵），只走字母路徑。這是給系統輸入法配合不好的裝置用的退路，做得可用即可，不必花太多篇幅。

### 引導練習中的鍵盤提示
使用系統鍵盤時無法在鍵盤上高亮按鍵，所以引導練習改在施法列上方顯示「下一個字母」的大字提示與鍵位小圖（畫一個小 QWERTY 示意圖標出位置）；使用內建鍵盤時則直接高亮鍵。

## 3. 先教學再打怪
每一關（王關與複習關除外）改成兩段：
- **引導練習**（沒有怪、沒有時間壓力、不扣血）：
  1. 看：一次介紹這關的 3～6 個新項目，每個項目一張卡（注音／國字、拼音、鍵盤上要按哪些鍵的動畫示範、一句記憶訣竅或常見錯誤）。
  2. 跟：畫面顯示答案，使用者照著用鍵盤打一次（施法列上方提示下一個字母與鍵位）。
  3. 試：隱藏答案，使用者自己打；打錯立刻顯示正解並要求重打一次。全部答對才進入打怪。
  約 1 分鐘內可完成；已三星通過的關卡再玩時可以按「跳過教學」。
- **打怪**：沿用現有戰鬥。第一次進入遊戲時，另有一段 30 秒的操作教學（怎麼鎖定、打錯會怎樣、偷看、連擊），用實際操作引導而不是一頁文字。
- 第 3 區易錯音的引導要用「成對比較」呈現（例如 zhi／zi、nan／lan、fan／fang 並排），讓使用者看出差別。

## 2. 明亮有質感的畫面
- 整體改成明亮、溫暖、有層次的風格：白天的天空與草地／森林／沼澤／山道／神殿，每區一套明亮的主色與場景插畫（內嵌 SVG，自己畫，原創）。現在的版本偏暗綠、平面、像後台介面，要擺脫這種感覺。
- 質感來自：細緻但克制的陰影與圓角、場景有前中後三層視差、角色與怪物有待機動畫（呼吸、眨眼、走路擺動）、命中有粒子與數字跳出、擊倒有消散效果、連擊有明顯但不擋字的提示、過關有慶祝動畫。動畫用 transform／opacity，手機上保持 60fps。
- 怪物每區至少 3 種造型（一般、快速、厚血）＋王，表情生動、可愛但不幼稚；術士與城門也重畫。不要 emoji、不要霓虹光暈、不要紫色漸層。
- 字體：系統中文字體堆疊；題目字要大（手機上國字至少 34px、鎖定時放大），拼音等寬。文字與背景對比至少 4.5:1。
- 預設用明亮主題；深色模式可保留為設定選項但不必跟隨系統。尊重 prefers-reduced-motion。
