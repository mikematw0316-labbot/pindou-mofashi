# 任務：拼音打怪網頁遊戲《拼音守城》（第一版）

使用者是台灣人，平常用注音，想練「漢語拼音輸入法」的打字速度。他嫌純練習無聊，要「打怪」的遊戲，同時要循序漸進、有教學感。在電腦上用實體鍵盤玩。介面一律繁體中文（台灣用語）。這是原創遊戲：不要模仿任何現成遊戲的名稱、角色、美術或關卡。

## 交付
- 只產出這個資料夾內的檔案：`index.html`（單一檔，CSS/JS 全部內嵌；不用任何外部函式庫、字型、CDN、圖片、音檔；離線直接雙擊可開）。
- `selftest.mjs`：用 Node（不裝套件）把 index.html 裡的題庫抽出來驗證（見「自我檢查」），`node selftest.mjs` 要全部通過並印出各區題數。
- `REPORT.md`：完成回報。
- 不要動這個資料夾以外的任何東西，不要 git、不要部署、不要裝全域套件。

## 核心玩法
畫面是一條橫向戰場（canvas 或 DOM 皆可）：左邊是玩家的城門與術士，怪物從右邊出現、往左走。每隻怪頭上頂著一個「題目」（注音符號、國字或詞）。玩家用鍵盤打出它的拼音就是攻擊：
- **鎖定**：打第一個字母時，自動鎖定「拼音以該字母開頭、且最靠近城門」的怪；鎖定後要把這隻打完（或按 Esc／Backspace 解除鎖定）。被鎖定的怪要有明顯標示，已打對的字母在怪頭上的拼音列逐一亮起。
- **打對**：每個正確字母都有命中回饋（小閃光、怪被打退一點點）；整組拼音打完，怪被擊倒（血厚的怪需要打完多個題目）。
- **打錯**：連擊歸零，被鎖定的怪往前衝一小步，並且在牠頭上亮出完整正確拼音約 1.5 秒（這是教學重點：錯了馬上看到正解）。該題記入「需要複習」。
- **提示**：預設怪頭上只顯示題目與注音小字，不顯示拼音；按 Tab 消耗一次「偷看」顯示目前鎖定怪（或最靠近的怪）的拼音，該次擊倒不算連擊。前兩個地區的新手關可以預設就顯示淡色拼音（教學），之後才隱藏。
- **連擊**：連續擊倒不出錯累積連擊，連擊越高得分倍率越高（例如每 5 連擊 +0.5 倍，上限 3 倍），並在畫面上有存在感。
- **受傷**：怪走到城門就扣城門血量並消失；血量歸零則失敗，可重來。
- **節奏**：怪的移動速度與出怪間隔隨關卡提升；同時在場的怪數量由少到多（新手關一次 1 隻，後面 3～5 隻），確保不同怪的拼音首字母盡量不同，避免鎖定歧義（若首字母相同，鎖定最靠近的那隻）。
- 第 1～4 區全域監聽鍵盤英文字母鍵，玩家不需要也不應該開輸入法；偵測到組字中（`event.isComposing` 或 keyCode 229）就暫停出怪並顯示「請先切回英文輸入」。
- Esc 暫停選單（繼續／重來／回地圖）。視窗失焦自動暫停。

## 進程：五個地區，每區數個小關＋一隻王
地圖畫面顯示五個地區與關卡節點，依序解鎖，每關顯示星等（1～3 星：過關／正確率 ≥ 90%／正確率 ≥ 95% 且未失血過半，數值寫成可調設定）與最佳速度。
1. **聲韻草原（聲母與韻母）**：怪頂著注音符號＋一個例字，打出對應拼音字母。小關依序：聲母 b p m f d t n l／g k h j q x／zh ch sh r z c s；韻母 a o e i u ü、ai ei ao ou／an en ang eng ong／結合韻 ia ie iao iu ian in iang ing iong ua uo uai ui uan un uang ueng üe üan ün。
2. **單字森林**：怪頂著一個國字（上方注音小字）。由常用字開始。
3. **迷音沼澤（易錯音專項）**：每種怪專考一組：zh/ch/sh 對 z/c/s、n 對 l、an/ang、en/eng、in/ing、ü 的規則（輸入法打 v：女 nv、綠 lv、略 lve；但 j q x y 後面的 ü 打 u：去 qu、學 xue、元 yuan、雲 yun）、iu/ui/un 縮寫（牛 niu、對 dui、春 chun）、y/w 開頭（一 yi、五 wu、魚 yu、月 yue、因 yin、英 ying、為 wei、文 wen）。
4. **詞語山道**：怪頂著兩到四字的詞（謝謝 xiexie、電腦 diannao、台灣 taiwan），要連續打完整拼音；這區的怪血較厚、走較慢。
5. **咒語神殿（真輸入法）**：這區不是走位戰，是與王對決：畫面顯示一句「咒語」（8～20 字日常句子），玩家切到自己系統的拼音輸入法，在輸入框打出一模一樣的中文並按 Enter 施放；王有蓄力條，蓄滿就攻擊玩家。必須正確處理組字（compositionstart／update／end，組字期間不可判錯也不可觸發其他快捷鍵），比對時忽略標點與全形半形差異，逐字標出錯字，錯字越少傷害越高。顯示每分鐘中文字數。

**王關**（每區最後一關）：王有多段血條，頭上一次出一題，連續打對才削血；打錯王會回一點血或加速蓄力。王的題目從該區「最容易錯」與玩家「需要複習」清單優先抽。

## 教學感
- 每關進場前顯示一張「怪物圖鑑／教學卡」：這關的怪考什麼、規則、2～4 個例子、常見錯誤；第 1 區附完整注音↔拼音對照表；第 5 區教 macOS 與 Windows 怎麼新增並切換到拼音輸入法（輸出繁體）、選字、詞語連打。Enter 開始。
- 結算畫面：星等、正確率、每分鐘擊倒字數（或字母數）、最長連擊、**最常打錯的 3 題與正確拼法**，以及跟自己上次成績的比較（變快／變慢多少）。
- 「複習清單」：打錯過的題目累積記錄，之後的關卡會較高機率再出現；地圖上有一個「複習關」可專打這些。
- 地圖上有「對照表」按鈕，隨時可看注音↔拼音表與 ü／y／w 規則。

## 成長（輕量，不要做太深）
過關得星星與金幣；金幣可在地圖上的小店升級少數幾項：城門血量上限、每關「偷看」次數、連擊保護（每關可免一次斷連擊）。全部存 localStorage（讀寫包 try/catch，讀不到也要能玩），有「重設進度」（二次確認）。

## 題庫要求（最重要：正確性）
- 用「不含聲調的漢語拼音」，ü 以輸入法實際要打的鍵為準（見第 3 區規則）。
- 多音字只選讀音沒有爭議的常用字／詞；台灣與大陸讀音不同的字詞不要放（例如 垃圾、企、液、期、和ㄏㄢˋ 這類）。
- 每筆資料同時有：國字、注音（台灣教育部標準）、拼音，兩者必須對得上。
- 題量下限：第 1 區涵蓋全部聲母與上列韻母；第 2 區 150 個單字；第 3 區每組至少 20 題；第 4 區 150 個詞；第 5 區 30 句。

## 自我檢查（selftest.mjs 必做）
1. 寫一個「注音 → 拼音（輸入法鍵入形式）」轉換函式（含 ü／y／w／iu／ui／un／zhi chi shi ri zi ci si 等規則），對題庫每一筆由注音算出拼音，必須等於題庫的拼音；不一致就列出並以非零狀態結束。詞與句逐字檢查。index.html 可共用同一函式產生提示，避免兩份資料不一致。
2. 每筆拼音只含 a–z；沒有重複題；詞的字數與注音音節數相符。
3. 各區題數達下限。
4. 每一小關的題池裡，檢查「可同時出場的怪」是否能湊出首字母互異的組合（否則調整該關同場怪數）。

## 視覺與互動
- 怪物與角色用內嵌 SVG 或 canvas 自己畫：造型原創、簡潔有個性（每區一種主題輪廓，王較大且有細節），不要用 emoji 當角色或圖示。
- 整體乾淨有設計感、不要像範本：有限的色盤與一個強調色、足夠留白、題目字要大而清楚（怪頭上的國字至少 40px，鎖定時放大）、拼音用等寬字。支援淺色／深色（跟隨 prefers-color-scheme）。不要霓虹光暈、不要滿版漸層。
- 命中、擊倒、受傷、連擊都要有短促的動畫回饋（150～300ms）；尊重 prefers-reduced-motion。音效可用 WebAudio 合成的短音（預設開，可關），不用音檔。
- 以 60fps requestAnimationFrame 更新，時間用 delta time；分頁隱藏時暫停。
- 視窗 1280×720 為主要目標；窄到 360px 不可破版（顯示「請用電腦鍵盤遊玩」的說明並仍可看地圖與教學）。
- 所有選單可用鍵盤操作，按鈕有可見的 focus 樣式。
