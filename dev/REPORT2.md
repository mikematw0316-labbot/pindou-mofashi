## 改版內容

- 改名《拼鬥魔法師》，預設明亮暖色；五區原創天空、草原、森林、沼澤、山道與神殿場景，三層視差、重新繪製魔法師與城門。每區怪物有一般、快速、厚血造型及王；快速怪移速較高、厚血怪至少兩題護甲。保留擊退、粒子、消散、連擊與過關慶祝，尊重 reduced-motion。
- 手機直式戰場：怪物由上往下、城門與魔法師在下方；精簡一列血量／連擊／進度。桌機沿用置中的直式戰場。最多同時三隻，各自佔一條軌道；可視高度不足 470px 時只保留一隻在前場，其餘保留進度並凍結等候，不刪除題目或改算擊倒。
- 使用 `100dvh`、safe-area、`viewport-fit=cover` 與 Visual Viewport 的高度、偏移及 resize／scroll 事件；固定戰鬥版面，鍵盤上方保留施法列。360px 以上的地圖、教學、商店、結算與對照表皆改為可捲動的手機卡片與拇指區操作。
- 每關先「看／跟／試」：介紹四個項目、鍵位順序動畫與訣竅，照答案打，再隱藏答案重打；錯誤立即揭答並要求重新輸入。第三區並排比較成對易錯音。王與複習關免引導，已三星關可跳過。首次另以實際點怪、打錯、偷看、擊倒／連擊操作教學帶入。
- 同一個常駐施法輸入框承接教學、字母戰與第五區整句。開始／繼續的點擊處理函式同步 focus；偵測到鍵盤縮小 Visual Viewport 後才倒數三秒，1.5 秒未偵測則走實體鍵盤備援。收起鍵盤、輸入框失焦、視窗失焦或分頁隱藏會暫停；點「點我繼續」重新 focus 並倒數，怪物及王蓄力均凍結。
- 字母判定支援 `beforeinput`、`input`、composition 系列事件、大小寫、空白、撇號與 ü→v。以 consumed 前綴保留已消耗的組字文字；組字期間不靠清空欄位連續擊倒，刪除會回退進度且不計錯。第 2～4 區也接受選字送出的完整國字／詞，優先已鎖定者及靠近城門者；對字母已擊倒後的國字提交與緊接的重複 input 去重。
- 注音符號會暫停，附 iOS 與 Android 繁體拼音的新增／切換步驟。第五區保留原本的整句正規化、編輯距離逐字標錯與 Enter 施放，使用相同開戰與暫停流程。
- 設定提供預設關閉的三排內建 QWERTY 鍵盤。以 pointerdown 判定、最近中心處理鍵縫及重疊邊緣，支援多指事件、按鍵回饋、偷看／刪除／解除鎖定；第 1～4 區可用，第五區仍使用系統輸入法。
- 保留五區三十關、鎖定、錯誤揭答、偷看、連擊倍率、王、城門血量、厚血詞語怪、複習清單、金幣小店、星等、最佳速度／上次比較與 localStorage 存檔。沿用原儲存鍵，以便第一版進度升級；舊的自動主題轉為預設淺色。

## 真機限制與退路

Gboard 的通用新增語言、選擇配置與長按空白鍵切換流程，已對照 [Google 官方說明](https://support.google.com/gboard/answer/7068494?co=GENIE.Platform%3DAndroid&hl=zh-Hant)。官方這份說明未保證每個地區、版本都有繁體拼音配置；找不到所需配置時，第 1～4 區可改用英文或內建鍵盤，第五區需要能輸出繁體的系統拼音輸入法。

- **未實測真機 iOS Safari、Android Chrome、實際系統鍵盤候選視窗，或 Apple／Gboard／Samsung／其他拼音輸入法。** Headless 以合成 composition／InputEvent 和 Visual Viewport 高度／resize 事件模擬；不能據此聲稱真實系統鍵盤一定彈出。
- 最可能的差異是 Safari 手勢焦點限制、候選列高度／網址列影響 Visual Viewport，以及第三方鍵盤對 compositionupdate.data 的空白、撇號與已送出前綴保留方式不同。開始／繼續按鈕同步 focus、保留常駐輸入框、1.5 秒實體鍵盤備援、鍵盤消失自動暫停與內建鍵盤是對應退路。
- 有些拼音輸入法只提供中文／注音形式的中間組字，而非拉丁字母。第 2～4 區可直接以完整繁體國字／詞作答；第 1 區為片段練習，請切英文鍵盤或使用內建鍵盤。無法從網頁強制切換系統鍵盤或變更繁簡輸出。
- 組字期間已由正確字母擊倒的題，送出同字不重複計分；若最後選出不同國字，會算選字錯誤。各家輸入法重寫或刪除已消耗組字前綴的特殊行為仍需真機確認；遇到不順時清空施法列重打，或改用內建鍵盤。
- 不支援 Visual Viewport 或使用外接鍵盤時採 1.5 秒備援。若手機瀏覽器未回報鍵盤高度，網頁無法可靠判別鍵盤是否開啟；可重新點繼續，或使用內建鍵盤。
- 未以真人逐一打完三十關，也未做真機效能／60fps 測量、長時間平衡、音效聽感或真人打字速度評估。全部題池與教學入口有檢查，代表關卡的自動通關範圍另列於驗證紀錄。
- file:// 下的存檔權限與位置由瀏覽器決定；讀寫失敗會提示暫存模式，仍可遊玩。第一版的讀音校對範圍與限制維持原報告及 STEP1.md。
