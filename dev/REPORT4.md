## 遊玩修正

- 一般怪原本的移動約需 40 秒，且小戰場可用行程很短。現在第一關約 16 秒，其餘一般關約 9～14 秒走到城門；減少底部預留空間，小視窗縮減怪物裝飾資訊，讓怪仍有可用行程。怪物持續踏步、搖擺、眨眼，最後四分之一行程有紅框與急促步伐。操作教學的怪也緩慢前進，在安全位置停下踏步，不扣血；城門前補上清楚的路徑。
- 第一關完整教 b／p／m／f／d／t／n／l 八個聲母，採「一次教完再打怪」。其餘關同樣先教本關尚未學過的全部項目；第三區保留四字成對比較。進度顯示本關題數與目前新學／複習項目的序號。
- 新增 learned 存檔，只有完成「試」的項目才記為實際學過；舊存檔不會憑星等被自動標成全部學過。錯題混入一般關時，也只取已實際教過、符合當區題型的項目。原有三星跳過教學、王關與複習入口保留。
- 第 1～3 區一般怪一題擊倒，移除原本依造型隨機多一層護甲的行為。第四區厚血怪及王有固定總格數與空格表示已扣血；每次命中立刻顯示「命中！」「還差 N 題！」，題卡翻動，王的血條持續更新原節點並有扣血動畫。
- 最後一擊會保留約 450ms 的戰場，讓火球命中、爆炸呈現後再進結算；期間停止後續輸入。長詞一次送入整串拼音、填滿小彈上限時，仍會保留大火球的名額。
- 每個正確字母有法杖閃光、小魔法彈與命中火花；完成答案有帶拖尾的大火球、爆炸環與粒子、擊倒文字、怪物旋轉縮小消散及輕微震動。五區分別使用綠、金、紫藍、橘紅與白金色魔法。城門受傷有紅閃；王有專屬受擊回饋。
- 連續兩次擊倒就有大字 COMBO ×N；5／10／15 有升階音效與得分倍率。Combo 會避開仍在作答的題卡，連擊歸零有「連擊中斷」。倍率文字依現有玩法標示「得分」，不虛稱增加傷害。
- 點選鎖定與首字母鎖定都有鎖定框及魔法師至目標的連線。重聽按鈕保留輸入焦點；拼音組字未送出、國字提交、英文鍵盤、內建鍵盤沿用同一套完整答案判定。偵錯面板新增獨立的「判定」行，顯示 raw、consumed、目標與最近的命中／擊倒／前綴／打錯原因。
- reduced-motion 時停用走路、眨眼、搖晃等持續或震動動畫，保留文字與短暫特效回饋；聲音不受此設定影響。

## 語音、音樂與音效

開始按鈕及其他按鈕的使用者手勢中建立／resume AudioContext，並同步 speak 極短的零音量 utterance。這修正了舊版直到第一個輸入事件才建立音效、可能錯過 iOS 手勢解鎖時機的問題；支援 webkitAudioContext 及被中斷後再次 resume。沒有手勢時不建立音訊圖、不 speak。

語音優先 zh-TW，否則使用排除香港語音的中文 voice，並顯示「此裝置沒有台灣中文語音」；完全沒有中文或沒有 Web Speech API 時，停止語音並說明原因。處理 voiceschanged 的延遲載入。出怪／切換目標時只讀目前鎖定者，否則讀最靠近城門者；同一題不自動重複。第一區讀例字，其他區讀國字／詞，第五區讀整句。看卡、跟／試指示、操作教學、打錯正解及勝敗均有語音；題卡與第五區可重聽。每次新提示先 cancel，正常取消不會被當成故障。沒有 API 或 API 丟例外都靜默降級，語音不阻塞遊戲。

音樂為本次程式編寫的原創音序，每首 8 小節、4/4 拍、每小節 16 個排程步。旋律、三和弦、低音及輕打擊各有聲部，沒有採用現成歌曲。王關使用同區主題、速度 ×1.2 並加低音／打擊；城門低於 30% 血量時加入緊張脈衝。

| 場景／曲名 | 調性 | 一般 BPM | 王關 BPM |
| --- | --- | ---: | ---: |
| 地圖／選單「晨光」 | C 大調 | 76 | — |
| 草原「芽風」 | D 大調 | 108 | 129.6 |
| 森林「木間光」 | F 大調 | 88 | 105.6 |
| 沼澤「霧珠」 | A 多利安調式 | 82 | 98.4 |
| 山道「踏石」 | G 大調 | 116 | 139.2 |
| 神殿「書光」 | E♭ 大調 | 72 | 86.4 |

音色以 sine／triangle Oscillator 與 Gain 包絡產生，音樂經低通、0.19 秒的少量回音。音序器每 25ms 補齊未來 180ms，以 AudioContext.currentTime 決定真正發聲時刻，不用 setInterval 直接觸發節拍。暫停、鍵盤收起及分頁隱藏時停止語音、淡出音樂；恢復倒數後淡入。語音播放時音樂壓至 24%，結束後恢復；遇到不回報結束事件的瀏覽器有超時保護。

取代舊嗶聲：正確字母（隨進度升高）、打錯、鎖定、命中、擊倒（隨連擊變亮）、Combo 升階、城門受傷、王蓄力／攻擊、偷看、倒數／開始、介面點擊、解鎖、逐顆星星、購買、過關與失敗，均有程式合成聲型。勝敗有短收尾樂句。同時音符上限 48，已結束 oscillator 與 gain 都 disconnect；總輸出經 DynamicsCompressor 抑制峰值。

設定頁有語音／音樂／音效各自的開關與 0～100% 音量、0.8／1.0／1.2 語速及兩顆測試按鈕，全部存檔。地圖與戰鬥都可總靜音，包含語音。首次載入地圖有「點任何按鈕後開始播放聲音」，不跳權限視窗。設定頁加上 iPhone 側邊靜音鍵與媒體音量提醒，並修正固定「完成」列遮住測試按鈕的問題。

## 已知限制與未驗證項目

**我無法聽到本次生成的聲音。** 以上驗證的是呼叫、文字、音量參數、排程、節點釋放與遊戲行為，沒有主觀聽感、曲目悅耳程度、實際揚聲器音量或音色平衡的聆聽驗收。

沒有真機 iPhone Safari、Telegram／LINE 內建瀏覽器或 Android 輸入法的實測。語音品質、可用中文 voice、首次手勢後是否允許 speak，以及鎖屏／來電後恢復，都取決於作業系統與內建瀏覽器；不支援時已準備靜默降級。Web Speech 使用系統語音服務，離線可用性也取決於裝置已安裝的語音。iPhone 側邊靜音鍵可能使 WebAudio 沒聲音；設定有提示，但沒有切換真機靜音鍵驗證。亦未量測真機 60fps、耗電與長時間背景恢復。

較大的關卡採一次教完全部未學項目，因此第一次引導會比舊版四張卡長；例如第二區總練習會補完先前沒有教過的字。這是為了保證不出未教題目，沒有刪減題庫。極小可視高度保留字題與輸入框，怪的絕對移動行程自然較短。

參考：[WebAudio 手勢解鎖建議](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)、[SpeechSynthesis cancel](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/cancel)、[voiceschanged](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event)。這些資料支持 API 處理方式，不能代替 iOS 真機驗證。
